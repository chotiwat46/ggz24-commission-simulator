# ggz24-commission-simulator

ระบบจำลองคำนวณค่าคอมมิชชันทีมไลฟ์สด (Automated Commission Simulator) พัฒนาเพื่อทดแทน Google Sheets ลดข้อผิดพลาด และปลอดภัยด้วย Role-Based Access

## 📋 ภาพรวมโปรแกรม (Overview)

* **รับไฟล์อะไร:** ไฟล์ Excel (.xlsx) ข้อมูลยอดขายประจำเดือน (Mock Data ปกปิดข้อมูลจริงแล้ว)
* **คำนวณอะไร:** คำนวณยอดขายสุทธิ (GMV) และค่าคอมมิชชันตามกติกาอัตโนมัติลง MySQL
* **แสดงผลอะไร:**
  * แดชบอร์ดสรุปยอดรวม (Total GMV และ Total Payout)
  * ตารางแสดงผลแบบเรียลไทม์ พร้อมค้นหาด่วน
  * ระบบสร้าง/ดาวน์โหลดใบสลิปค่าคอมมิชชันดิจิทัล PDF

## ⚙️ กติกาการคำนวณคอมมิชชัน (Calculation Rules - 3 ตัวอย่าง)

| ตัวอย่างที่ | ยอดขาย (GMV) | อัตราเรทคอมมิชชัน (%) | คอมมิชชันที่ได้รับ (บาท) | สูตรคำนวณ |
| :--- | :--- | :--- | :--- | :--- |
| 1 (มาตรฐาน) | 100,000 ฿ | 2% | 2,000 ฿ | 100,000 × (2/100) |
| 2 (แคมเปญพิเศษ) | 250,000 ฿ | 5% | 12,500 ฿ | 250,000 × (5/100) |
| 3 (ระดับเริ่มต้น) | 50,000 ฿ | 2% | 1,000 ฿ | 50,000 × (2/100) |

## 📁 โครงสร้างโปรเจกต์ (Project Structure)

* `backend/` : Node.js, Express + MySQL
* `frontend/` : React + Vite
* `data/` : เก็บไฟล์ `sample_commission.xlsx` (ตัวอย่างข้อมูลจำลอง)
* `src/` : ซอร์สโค้ดหลักของโปรเจกต์
* `docs/` : เอกสารและภาพหน้าจอหลักฐานการคำนวณ
